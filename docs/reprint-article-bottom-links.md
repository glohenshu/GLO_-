# 再掲連載作成アシスタント：記事下リンクを取得・組み立てる仕組み

対象：https://reprint-assistant.vercel.app/ の **② 記事下** タブ
コード：`apps/reprint-assistant/api/reprint-data.js`（取得）／`apps/reprint-assistant/app.js`（判定・組み立て）
作成：2026/11/24（本番の `gr2083` の応答で動きを確かめた）

`docs/reprint-handover.md` の §6・§10・§12・§13 に散らばっている話を、データの流れに沿ってつなげたもの。
ルールの経緯（いつ誰の指示で変えたか）は引継ぎメモ側に残っている。

---

## 1. 全体の流れ

```text
[Googleスプレッドシート「毎月の記事下リンク」]  B列＝期間 / C列＝記事下HTML
        │  GASウェブアプリ（SHEET_GAS_URL）が { values: [[B, C], ...] } を返す
        ▼
[api/reprint-data.js]  fetchSheetData()
        │  kintone（GLO連載情報・記事データ341）と並行に取得し、
        │  sheet.rows にそのまま入れて返す。行の選別はしない
        ▼
[app.js]  fetchReprintData()
        │  state.sheetRows に保存
        ▼
  各回の公開予定日を出す       buildRows()      第1回配信日時 ＋（回数−1）日
        ▼
  シートの行に年を付ける        assignRowYears() B列に年が無いため、曜日で採点して推定
        ▼
  公開予定日を含む週の行を探す  findSheetRowForRow()  下の行から順に見る
        ▼
  C列HTMLを再掲用に直す         buildArticleBottomHtml()
        │   ① 【注目記事】【人気記事】の段落を落とす（回によって違う）
        │   ② gr●●●● → カテゴリコード、●●●●●●●● → 書籍名
        ▼
  先頭に「この話の続きを読む」をつなぐ  joinBottomHtml()
        │   続きを読む＝参照元の第(N+1)回（最終回は固定文言）
        │   C列先頭の余白段落 <p>　</p> を1つだけ落とす
        ▼
  「記事下まとめてコピー」ボタン
```

**シートは検索のたびに取り直す**（API は `Cache-Control: no-store`）。シートを直したら、画面で「検索」を押し直せば反映される。

## 2. 元データ：スプレッドシート「毎月の記事下リンク」

1行＝1週間。新連載作成アシスタント・新規一括集中アシスタントと同じシートを使っている。

| 列 | 中身 | 例 |
|---|---|---|
| B列 | 見出し＋期間（セル内改行あり） | `11月第三週`⏎`11/15（日）〜11/21（土）` |
| C列 | その週の記事下に貼るHTML | 下の例 |

C列の実例（`12/20（日）〜12/26（土）` の行。2026/11/24時点）：

```html
<p>　</p>
<p><span style="font-size:20px;">👉<a href="/category/gr●●●●" target="_blank"><span style="color:#0000FF;">『●●●●●●●●』連載記事一覧は<u>こちら</u></span></a></span></p>

<p><a href="/articles/-/28338" target="_blank"><strong><span style="color:#0000CD;">【イチオシ記事】…</span></strong></a></p>

<p><a href="/articles/-/27951" target="_blank"><strong><span style="color:#0000CD;">【注目記事】…</span></strong></a></p>

<p>　</p>
<p>ゴールドライフオンライン（GLO）は、表現者を応援するウェブメディアです。<br />…</p>
```

並びは **余白 → 連載記事一覧 → 【イチオシ記事】 → 【注目記事】 → 余白 → GLO定型文**。古い行には【人気記事】も入っている。

シートの性質で、仕組みが前提にしていること：

- **B列に年が書かれていない**。1年以上分の行が上から下へ時系列で積み上がっている（2026/11/24時点で91行。先頭は空行2行のあと `4月(前半) 4/1～15`）
- **週の行が先に作られ、C列は後から入る**。行はあるのにC列が空、という状態が普通に起きる（同時点で `12/27〜1/2` と `1/3〜1/9` の行はC列が空）
- B列の期間の書き方は3通りある（§4-1）

## 3. 取得：API（`api/reprint-data.js`）

### 3-1. 取り方

`fetchSheetData()` が `SHEET_GAS_URL` を `fetch` し、返ってきたJSONの `values` をそのまま `rows` にする。

- 会社のWorkspaceポリシーで外部共有が禁止されているため、Sheets API は403になる。**GASウェブアプリ経由が本線**
- GASのデプロイは「アクセスできるユーザー＝**全員**」が必須。組織内限定だとJSONではなくログインHTMLが返る。そのときは「GASがJSONではなくHTMLを返しました（デプロイのアクセス権を「全員」にしてください）」と出す
- `SHEET_GAS_URL` が無いときだけ Sheets API（`SHEET_ID` / `GOOGLE_API_KEY` / `SHEET_NAME`、範囲 `B:C`）を使う。今は使っていない
- GASのURLはサーバー側だけで使い、画面には出さない

GASのスクリプト自体はこのリポジトリに入っていない（`gas/` にあるのは夜明けの `yoake-links.gs` だけ）。返す形は `{ values: [[B列, C列], ...] }`（README の記載）。

### 3-2. 失敗しても止めない

`fetchSheetData()` は例外を投げない。kintone 2件と**並行に**取得し、シートだけ失敗しても連載情報・参照元・①前回記事・③次回更新日はそのまま使える。

失敗したときは `sheet.status = 'error'` と理由を返し、`warnings` に「記事下データ（スプレッドシート）を取得できませんでした：…」を足す。

### 3-3. 返す形

```json
"sheet": {
  "status": "ok",
  "message": "",
  "rows": [["11月第三週\n11/15（日）〜11/21（土）", "<p>　</p>\n<p>…"], ...],
  "rowCount": 91
}
```

### 3-4. 診断用 `?summary=1`

```text
https://reprint-assistant.vercel.app/api/reprint-data?code=gr2083&summary=1
```

`rows` を返さず、件数・取得経路（`via`）・**末尾5行のB列**（`samplePeriods`）だけを返す。シートが最新の週まで作られているかをすぐ確かめられる。

## 4. 画面側：どの週の行を使うか（`app.js`）

### 4-1. B列から月日を取り出す：`parsePeriodParts()`

B列のうち「数字/数字」を含む最初の行を読み、開始と終了の月日を取る。見出し行（`11月第三週`）は読み飛ばす。

| 書き方 | 読み取り結果 |
|---|---|
| `8/23（日）〜8/29（土）` | 8/23〜8/29 |
| `6/1（日）～7（土）`（終了側が日だけ） | 6/1〜6/7（終了の月は開始と同じとみなす） |
| `4/1～15`（曜日なし） | 4/1〜4/15 |

- 波ダッシュは `～`(U+FF5E)・`〜`(U+301C)・`~` のどれでもよい
- 月が13以上・日が32以上のものは読めなかったものとして扱う（その行は使わない）

### 4-2. 行ごとの年を推定する：`assignRowYears()`

B列に年が無いので、**最後の行の年を決めてから、上へ向かって年を割り当てる**。上の行へ進んで月が大きくなったら（12月→その上が11月なら同じ年、1月→その上が12月なら前の年）、年を1つ戻す。

最後の行の年は、今年の前後（去年の前年・去年・今年・来年の4通り）を試して決める：

1. **B列の曜日と合う行の数**で採点する。`11/15（日）` と書いてあれば、その年の11/15が日曜かどうかを全行で確かめる。曜日は年を一意に決めるので、ここでほぼ決まる
2. 同点のときだけ、最後の行の日付が今日に近い年を採る

「今日に近い年」だけで決めないのは、シートが何か月も更新されていないと年がずれるため。

2026/11/24時点の結果：末尾 `12/27（日）〜1/2（土）` → 2026年、`1/3（日）〜1/9（土）` → 2027年。

推定結果はシートを取り直すまで使い回す（`getParsedSheetRows()`）。

### 4-3. 各回の公開予定日：`buildRows()`

今回の記事はまだ記事データアプリに無いので、**GLO連載情報の「第1回配信日時」を日本時間で読み、1日ずつ足す**（再掲は毎日更新）。

- kintoneの日時はUTCで返るので、`parseJstParts()` で必ず Asia/Tokyo に直す
- 第1回配信日時が未登録だと公開予定日が出せず、記事下は「公開予定日を算出できません」になる

### 4-4. 週の行を探す：`findSheetRowForRow()`

公開予定日（時刻は落として日付だけ）が、その行の開始日〜終了日に入るかを見る。

- **シートの一番下の行から上へ**探し、最初に入った行を使う。同じ週が2行あれば下の行が勝つ
- 12/27〜1/2 のような年またぎは、終了側の年を1つ進めて比べる
- 見つからなければ「該当なし」。**近い別の週や別の年の同じ週で代用しない**（古いリンクを貼らないため）

`gr2083`（第1回 2026/11/20、全24回）で実際に当たった週：

| 回 | 公開予定日 | 使う行（B列） |
|---|---|---|
| 第1〜2回 | 11/20〜11/21 | 11/15〜11/21 |
| 第3〜9回 | 11/22〜11/28 | 11/22〜11/28 |
| 第10〜16回 | 11/29〜12/5 | 11/29〜12/5 |
| 第17〜23回 | 12/6〜12/12 | 12/6〜12/12 |
| 最終回 | 12/13 | 12/13〜12/19 |

1つの連載でも、**回ごとに公開される週のC列を使う**（第1回の記事下と最終回の記事下でイチオシ記事が違う）。

## 5. 画面側：C列を再掲用に直す（`buildArticleBottomHtml()`）

### 5-1. 段落を落とす：`removeDroppedParagraphs()`

| | 通常回 | 最終回 |
|---|---|---|
| 連載記事一覧 | 残す | 残す |
| 【イチオシ記事】 | 残す | 残す |
| 【注目記事】 | **落とす** | **残す** |
| 【人気記事】 | 落とす | 落とす |
| 余白・GLO定型文 | 残す | 残す |

- 判定は `【注目記事】` `【人気記事】` という**ラベルそのもの**で行う。「注目」「人気」だけで探すと、書籍名の `［注目連載ピックアップ］` まで消してしまう
- ラベルを含む `<p>…</p>` を段落ごと消す。`<p align="center">` の段落や、途中に改行が入った段落もある
- 置き換え（5-2）より**先に**落とす。書籍名を入れてから消すと、書籍名しだいで結果が変わりうるため

### 5-2. プレースホルダーを置き換える

| C列の文字 | 置き換え先 |
|---|---|
| `gr●●●●` / `grxxxx` | カテゴリコード |
| `●●●●●●●●` / `xxxxxxxx` | 書籍名 |

`gr●●●●`（●4つ）を先に置き換える。`●●●●●●●●`（●8つ）を先にすると、●4つの方が壊れる。

**どの連載に誘導するかは回によって変える**（`getListTarget()`）：

| | 一覧のリンク先 | 表示する書籍名 |
|---|---|---|
| 通常回 | `/category/参照元のコード`（例 gr1823） | 『記憶のなかで生きる』 |
| 最終回 | `/category/今回のコード`（例 gr2083） | 『記憶のなかで生きる』 |

通常回の時点では今回の再掲の一覧がまだ揃っていないので、全話そろっている参照元へ送る。最終回で今回の一覧へ送る。

書籍名は、`［…ピックアップ］` の形の表記を外し、さらに書名全体が『』で囲まれていれば外す（テンプレート側に『』があるので二重にしない）。

## 6. 先頭に「この話の続きを読む」をつなぐ

### 6-1. 続きを読む：`resolveNextLink()`

今回の第N回の記事下には、**参照元の第(N+1)回**へのリンクを置く。公開日ではなく回数で対応させる。

```html
<p>▶この話の続きを読む<br />
<span style="font-size:18px;"><a href="/articles/-/記事ID" target="_blank"><span style="color:#0000FF;">記事タイトル</span></a></span></p>
```

記事ID・記事タイトルは記事データアプリ（341）の参照元の記事から取る。記事タイトルに記号の化け（`??` など）があると「要確認」が出る。

最終回は続きの代わりに固定文言にする：

```html
<p align="center">試し読み連載は今回で最終回です。ご愛読ありがとうございました。</p>
```

### 6-2. つなぎ方：`joinBottomHtml()`

**続きを読む（または最終回の文言）→ C列** の順でつなぐ。並べ替えない。

C列の**先頭にある余白段落だけ**を1つ落とす（`dropLeadingSpacer()`）。中身が全角空白・`&nbsp;`・`<br />` だけの段落を余白とみなす。途中の余白（定型文の前など）は残す。

### 6-3. 完成形の実例（`gr2083`、参照元 `gr1823`）

第1回（2026/11/20、11/15〜11/21の行）：

```html
<p>▶この話の続きを読む<br />
<span style="font-size:18px;"><a href="/articles/-/25401" target="_blank"><span style="color:#0000FF;">突然亡くなった父の葬儀で、母は一粒の涙も見せなかった…でも、その日の夜、母は父の寝室で…</span></a></span></p>
<p><span style="font-size:20px;">👉<a href="/category/gr1823" target="_blank"><span style="color:#0000FF;">『記憶のなかで生きる』連載記事一覧は<u>こちら</u></span></a></span></p>

<p><a href="/articles/-/24900" target="_blank"><strong><span style="color:#0000CD;">【イチオシ記事】…</span></strong></a></p>

<p>　</p>
<p>ゴールドライフオンライン（GLO）は、表現者を応援するウェブメディアです。<br />…</p>
```

最終回（2026/12/13、12/13〜12/19の行）：

```html
<p align="center">試し読み連載は今回で最終回です。ご愛読ありがとうございました。</p>
<p><span style="font-size:20px;">👉<a href="/category/gr2083" target="_blank"><span style="color:#0000FF;">『記憶のなかで生きる』連載記事一覧は<u>こちら</u></span></a></span></p>

<p><a href="/articles/-/28334" target="_blank"><strong><span style="color:#0000CD;">【イチオシ記事】…</span></strong></a></p>

<p><a href="/articles/-/28534" target="_blank"><strong><span style="color:#0000CD;">【注目記事】…</span></strong></a></p>
```

## 7. コピーできないとき：画面の表示と原因

誤ったHTMLを貼らないよう、揃っていない回は**ボタンを無効にして理由を出す**（`bottomCopyBlockReason()` / `sheetBlockReason()`）。

### 7-1. 記事下（シート）側

「記事下リンク」欄の表示と、確かめる場所：

| 画面の表示 | 原因 | 確かめる・直すところ |
|---|---|---|
| スプレッドシートを取得できませんでした（＋理由） | GASが落ちている／アクセス権が「全員」でない／環境変数が無い | GAS URLをシークレットウィンドウで開いてJSONが返るか。上部の「記事下データ：取得失敗（…）」にも理由が出る |
| 公開予定日を算出できません | GLO連載情報の第1回配信日時が未登録 | kintoneの連載レコード |
| 該当期間が見つかりません（予定公開日：…） | その週の行がシートにまだ無い | シートに週の行を足す。`?summary=1` の `samplePeriods` で最後の週を見る |
| 2026/12/27〜2027/1/2（C列が空です） | 行はあるがC列が未記入 | シートのC列を埋める。**一番多い原因** |

「記事下リンクが取れない」と言われたら、まず**C列が空かどうか**を疑う（新連載作成アシスタントと同じ。`docs/handover.md` §5-2-1）。

### 7-2. 続きを読む（参照元）側

| 画面の表示 | 原因 | ボタン |
|---|---|---|
| 参照元を選択してください | 参照元が未選択・候補なし | 無効 |
| 参照元に該当回がありません | 参照元より多い回数で再掲している | シート側が揃っていれば「記事下テンプレをコピー」（続きを読むのリンク先を `●●●●●`、タイトルを `●▼■` にしたもの。MWで差し替える） |
| 参照元 第N回 に記事IDがありません | 記事データ341の記事IDが空 | 無効 |

最終回はシート側が揃っていれば常にコピーできる（続きを読むが要らないため）。

## 8. 注意点・弱いところ

- **年の推定がずれると、別の週のリンクを貼る**。曜日で採点しているのでまず起きないが、B列から曜日が消えると「今日に近い年」頼みになる。拾った行はセルにマウスをかざすと出る（`シートB列：…` と `一覧：/category/…`）ので、怪しいときはそこで確かめる
- **同じ週の行が2つあると、下の行が使われる**。行を作り直すときは古い行を消すか、下に新しい行を置く
- **1日に1本の毎日更新が前提**。公開予定日は第1回配信日時から1日ずつ足すだけなので、途中で休みがある連載はずれる
- **GASの一時的な404を取り直していない**。新規一括集中アシスタントは404のときだけ1回取り直す（`bulk-data.js` の `GAS_RETRY_STATUS`）が、再掲側には無い。たまに取得失敗になったら「検索」を押し直せば取れることが多い
- GASのスクリプトがリポジトリに無いので、返す列（B・C）や `getValues` / `getDisplayValues` の違いはGASエディタで確かめるしかない
